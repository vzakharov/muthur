## 3. Intent

The Opus review of weaker sessions' work must not depend on the weaker model's
brief or on its own bookkeeping. Reuse `/polish`'s floor and subagent launch;
the only hard enforcement is the git-read closing gate; everything else is
instruction text.

## 4. Decisions

- **Review = third pass of `/polish`** (`passes.md`), not a separate reviewer
  file or transcript cutoffs. Floor = newest full `polish:` commit.
- **Verdict lives in the polish commit's `Review:` line**, written by the Opus
  subagent as the run's last commit; no `verdict` command, no session recording.
  Alternatives beaten: separate review commit/cutoff marker (a run can stop
  between), session-run command (leaves the step to the weak model).
- **Gate keys on cutoffs the session entered** (per-session state) and reads the
  verdict from git; it ignores working-artifact commits
  (`docs/issue|pr| remove-before-merging`, plan deletions/renames);
  `polish: restore` and focused runs leave it shut until a full `/polish`. The
  `Bash` gate matches command position, not commit-message bodies.
- **No hook on `Agent`, no agent definition**: recognising a polish launch is a
  heuristic a long brief walks around; the operator ruled it out («не будем
  большими католиками чем папа Римский»). Instead `passes.md` opens by telling
  the reviewer to ignore the launcher's words.
- **Transcript reading is optional** (`scripts/session-qa.py`, `--since`,
  `--tools`), read when the written record and git history disagree.
- Capabilities file renamed/moved to `.claude/model-capabilities.md`; `/plan`
  gains a polish step for sessions below Opus; the change is a `fix:`.
