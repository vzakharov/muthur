```
An adopting repo's environment holds its own settings beside muthur's,
and names like INTERVAL or COLD_CACHE_GUARD said nothing about which
tool reads them, and could collide with a project's own.

Every variable muthur itself defines and reads now carries the MUTHUR_
prefix: MUTHUR_CONTEXT_BUDGET_{WARN,PAUSE,PAUSE_SAVING,LINES},
MUTHUR_COLD_CACHE_{GUARD,MIN_USD,MARGIN},
MUTHUR_TELEMETRY_RECEIVER_PORT and the CI watch's MUTHUR_INTERVAL, each
renamed with every hook, test, skill, catalog row and CLAUDE.md that
states it. Variables other tools own (Claude Code's, GitHub's, OTEL_*)
keep their names, as do the cache keepalive's, renamed by #181.

Adopters: the old names are no longer read, and the defaults apply
silently. Ask your operator whether any of them is set in their cloud
environment's variables, a shell profile or .claude/settings.local.json,
and to rename each to its MUTHUR_ form; that edit is theirs, since none
of those places is in your tree.
```
