```
An elephant plan grows by a bite's worth of `## Eaten so far` every
session, and each resume pays for every line it holds, so a long-lived
elephant ends up taxing every bite with its whole history.

Past 450 lines the plan now splits into files beside it, down to under
400. The lifecycle-named file stays the plan, its name being the gate,
and keeps the loop, the rest of the elephant and the open bite.
`## Eaten so far` becomes a fixed-size summary that each bite's end
rewrites, plus an index row per bite pointing at
`docs/plans/<slug>/bite-<nn>.md`; standing decisions move to
`docs/plans/<slug>/decisions.md`. A resume opens only the files its
slice touches.

The trigger and the target differ on purpose: a single threshold would
have every later bite trimming a few lines to stay under it. The
directory goes out with the plan in `/finalize`'s existing sweep.
```
