```
The Stop hook committed the session's cost row to the working branch on
every turn, so a branch's history was mostly cost-row commits. Since
cost-ledger became the rows' source of truth, the branch copy exists
only so the PR diff shows what the work cost, and the agent's own
commits are enough to carry it.

A PreToolUse hook now prices the session and stages its row just before
a git commit, so the row rides that commit. It stays out of the trunk
and finalized branches, a delegate's worktree, an in-progress merge or
rebase, any command naming the rows' directory (/finalize's sweep), and
a commit that would hold nothing but the row.

The Stop hook still writes cost-ledger every turn but no longer commits
to the branch. A row that no commit took is put back to HEAD's copy, so
the harness's git check never finds the tree unclean. A session that
never commits leaves no copy on the branch; the ledger still counts it.
```
