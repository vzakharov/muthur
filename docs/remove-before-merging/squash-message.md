```
The Claude app refuses to send a command whose argument carries another
slash command, so `/relay /go` and `/from-branch #123 /finalize` never
reached the session. The check is the client's own and no skill setting
lifts it, so the loop stops asking for that form.

A skill named inside another skill's argument is now written bare --
`/relay go`, `/from-branch #123 finalize` -- in descriptions, examples
and every command a skill hands the operator to type. The convention
lives in .claude/rules/skills.md, together with its reading: a first
token naming a directory under .claude/skills/ is that skill, slash or
no slash, since the CLI still sends the slashed form.

/from-branch's argument shape and Step 6 read a bare skill follow-up
that way, which is also how `/relay take` dispatches the successor's
first message. /relay, /go, /finalize and /check-merge spell their
nested examples bare.
```
