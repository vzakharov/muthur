```
The /update-muthur nudge checks the sync lock when it runs, but an
agent can make its offer hours later, or repeat it after a relay, by
which time a parallel session may already hold the sync.

The nudge's offer rules and /update-muthur § "Offered at session
start" now have the agent run `git ls-remote` on the lock right before
making the offer and before each repeat, and drop the offer on any
output. The nudge prints the lock's literal name. A landed sync leaves
its lock behind, so the same check also catches that.

trunk_ref() also asks origin for its default branch and fetches it
when no trunk ref is on disk. A session cloned single-branch onto a
non-trunk branch now gets the nudge instead of "no trunk ref".
```
