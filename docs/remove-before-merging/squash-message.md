```
Claude Code reaches people who cannot open a terminal only when
something else holds the conversation for them. leisan-psy-work does
that with an agent chat. This plans the version where a button does
it instead, so the same arrangement reaches anyone: a front end
writes a request to a queue, an isolated run reads the row and
answers it, and the person never meets a branch.

The run happens in GitHub Actions inside the requester's own estate,
on their subscription, driven by one repository_dispatch per
request — so there is no dispatcher process to keep alive, and a
failure queues rather than compounds. It invokes the bare CLI rather
than claude-code-action, whose actor check rejects a bot dispatcher
outright and whose GitHub App carries twelve permissions none of
this needs. Only a request id crosses into the run; the row's
contents are data the skill reads, never instructions it follows.

The lane was chosen from measurements, recorded in the plan so they
are not rediscovered: routine fires are capped at five a day on Pro
and fifteen on Max, a cloud container holds no account credential,
create_session is present in ordinary cloud sessions and absent in
routine-fired ones, and it recurses with no depth limit and no
parental authority. The session lane stays in the plan as a
described alternative — sessions for succession, subagents for
work — because it is functional, only undocumented.

The thin template that app authors fork is a build artifact of the
engine repository rather than a second tree kept in step by hand,
which is what keeps the two from diverging silently.
```
