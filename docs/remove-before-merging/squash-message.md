through, the hard part is the wording: the classifier lets a soft-denied
action pass once an operator message names it directly and specifically,
and a general "go ahead" does not count.

PermissionDenied half records each denial under tmp/; its Stop half

copy-pasteable message per still-needed action, named exactly and never
softened, or say why no phrase can help (a settings deny rule, a hard
block). It runs as a pair because PermissionDenied has no channel to the
agent, and it returns no retry, since a retry before the operator writes
that message meets the same verdict.
