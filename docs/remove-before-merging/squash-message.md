```
A transcript naming a dated snapshot id such as
claude-haiku-4-5-20251001 could not be priced: prices.json carries only
the undated claude-haiku-4-5 row, so pricing raised UnpricedError and
the session got no ledger row at all.

PriceTable.rates_for now falls back from a `-YYYYMMDD` id to its
undated row when the dated one is absent. A dated row of its own still
wins, and a model with neither row still raises, since the table is
kept by hand and a response counted as free is worse than no row.
byRate keeps the id the response named, the key telemetry already
files Haiku's background calls under.
```
