```
A UserPromptSubmit hook receives a prompt's text and never its
attachments, so a prompt the cold-cache guard stopped lost its images:
`!` replayed the text alone and the model answered without them.

Claude Code saves each attached image to the `images/` directory beside
`scratchpad_dir` before the hook runs, blocked prompt or not. On a block
the guard now copies the images newer than the last response into
`tmp/cold-cache/<session>.images/`, since a restart can reuse a number,
and records them with the stopped prompt. The block message says they go
with `!`, and `!`'s context lists the copies for the model to Read.
Without a scratchpad or an images directory the guard behaves as before.
```
